## DevOps란?

개발(dev)과 운영(ops) 사이의 벽을 없애 생산성과 안정성을 함께 높이는 일하는 방식이다. 직무로서는 코드가 안전하고 빠르게 운영 환경까지 가서 잘 돌아가도록 그 길을 만들고 관리한다.

---
## 하는 일과 효과

1. **CI/CD**
    - ops가 요구하는 검증 절차를 자동화해 파이프라인에 통합하므로, dev의 속도를 막지 않으면서 안정성을 확보한다.
    - 매번 같은 방식으로 작게 배포하고 쉽게 되돌릴 수 있어 변경 하나하나의 위험이 줄어든다.

2. **observability**
    - dev와 ops가 같은 데이터를 보게 되어 문제를 빨리 발견하고 원인을 빨리 찾는다.
    - 운영 결과가 개발로 빠르게 돌아가 다음 변경에 반영된다.

3. **Platform Engineering**
	- 이미지, 매니페스트, 인프라 코드로 실행 환경과 배포 방식을 표준화해, 환경 차이로 인한 문제를 줄이고 어디서나 같은 방식으로 실행, 확장, 복구할 수 있게 한다.
	- 이 표준을 셀프서비스 플랫폼으로 제공해, 개발팀이 인프라를 다 알지 못해도 운영까지 스스로 책임질 수 있게 한다.

> cf) **DevSecOps**: 마지막에 몰아서 하던 보안 검사(취약점 분석, 코드 분석, 컨테이너 취약점 등)를 코드, 빌드, 이미지, 배포, 운영 전 구간에 앞당겨 자동으로 넣는 것(Shift Left). 보안이 병목이 되거나 생략되는 것을 막고, 취약점을 일찍 발견해 고치는 비용을 줄인다.
